Step 1 of 4

Create your Google Sheet

CallLog saves everything to a Google Sheet you own. First, let's create the sheet with the right structure.

1. Open sheets.google.com and create a new spreadsheet.
2. Create two tabs at the bottom — name them Calls and Distributors.
3. In each tab, add the header row below in Row 1:

Calls tab — Row 1:

Date  |  Contact  |  Number  |  Company  |  Area  |  Category  |  Notes  |  Follow-up  |  Last Purchase  |  Synced At

Distributors tab — Row 1:

Name  |  Phone  |  Company  |  Area  |  Last Purchase

After adding headers, fill in your distributors in the Distributors tab — one per row.

Step 2 of 4

Share your Sheet

CallLog needs write access to your sheet to save call logs.

1. In your Google Sheet, click Share (top right).
2. Under General access, change to Anyone with the link.
3. Set the role to Editor.
4. Click Done.

⚠ This lets anyone with your Sheet URL edit it. Keep your Sheet URL private — only you will have it.
Step 3 of 4

Get a Google API Key

This lets the app read and write to your sheet. Takes about 2 minutes.

1. Go to console.cloud.google.com.
2. Create a new project (or use an existing one).
3. Go to APIs & Services → Enable APIs → search for Google Sheets API → Enable it.
4. Go to APIs & Services → Credentials → + Create Credentials → API Key.
5. Copy the API key shown.

🔒 Recommended: After copying your key, click Edit on it → under API restrictions, select Google Sheets API only. This means even if someone finds your key, they can only access Sheets — nothing else in your Google account.
